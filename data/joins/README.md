# Join practice datasets

Placeholder for related tables used in lectures and guided practice. No datasets have been selected yet.

Create a topic folder for each collection, with descriptive CSV filenames and a README documenting sources, column meanings, units, and join keys. Keep examples small. Explain a join as combining related tables using a shared column.

Weeks 6 through 8 cover primary keys (unique row identifiers), foreign keys (references to another table), cardinality (how many rows can match), joins, unmatched records, and join validation. Check key uniqueness, missing keys, and row counts before and after joining. Lab 3 explicitly assesses these required skills and is worth 10% of the course grade.

Joins are optional in the final project. Both the single-dataset and relational pathways can earn full credit; using a join does not earn automatic extra credit.
