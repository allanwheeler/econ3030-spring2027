# Final project datasets

Reserve three curated dataset choices here. The numbered folders are placeholders until topics are selected. No project CSVs are present, so sources, real or synthetic status, variables, and relationships are not yet known.

## Two pathways

- **Single-dataset pathway:** analyze one CSV using Polars transformations and Altair visualizations.
- **Relational pathway:** join two related CSVs, validate the join, and complete the same analysis.

Joins are optional. Both pathways are eligible for full credit. Grade data preparation, visualization, economic reasoning, and interpretation rather than the number of datasets or use of joins. Do not award automatic extra credit for joining datasets.

Keep the three choices comparable in size and difficulty. Each choice must support a complete single-CSV analysis. Where related tables are available, offer the relational pathway as an option.

## Documentation

Every project folder must have a README with an overview and verified source, real or synthetic status, what each row represents, a data dictionary with units and missing-value conventions, limitations, table relationships if applicable, and two or three introductory analytical questions. Inspect actual files before documenting definitions. Flag unknown details rather than guessing. Confirm redistribution permission before sharing data.
