## Your task

Use a new fictional group with students F, G, H, I, and J and study hours 1, 3, 4, 6, and 6.

1. Replace the student labels and hours in the table cell. Keep the column names unchanged.
2. Run the table, mean, and chart cells again.
3. Give the chart a title that identifies the new group.
4. Add a Markdown cell answering: What is the mean? Which students studied more than the mean? What is one reason these data cannot describe all university students?

The practice notebook contains all the code patterns you need. Explain your result in two to four sentences.
